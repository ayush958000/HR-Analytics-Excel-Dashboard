📌 Project Overview

This project analyzes employee data to understand workforce characteristics and employee attrition using Microsoft Excel.
The dashboard provides an interactive view of key HR metrics such as employee count, attrition, attrition rate, average monthly income, department distribution, education level, job roles, gender distribution, work-life balance, and years at the company.

🎯 Project Objectives

-Analyze employee attrition and workforce trends

-Understand employee distribution across departments and job roles

-Analyze employee demographics

-Track key HR performance indicators

-Create an interactive and easy-to-understand HR dashboard

🛠️ Tools & Technologies

-Microsoft Excel

-Pivot Tables

-Pivot Charts

-Slicers

-Data Cleaning

-Data Analysis

-Dashboard Design

📌 Key Insights

-Employee attrition analysis

-Department-wise employee distribution

-Job role analysis

-Employee satisfaction trends

-Salary and experience analysis

-Workforce demographics
